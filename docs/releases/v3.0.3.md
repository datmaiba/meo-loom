# MeoLoom 3.0.3

MeoLoom 3.0.3 makes failed quality gates actionable and keeps property-scoped
validator tests independent from unrelated repository findings.

## Changes

- Document a red-gate recovery flow: classify the cause, retain exact evidence,
  assign controller ownership, rerun only after a relevant change, and close
  only after every required final gate passes.
- Require QA to report cause, evidence, and the condition for a rerun while
  preserving its independent stop-and-report role.
- Make validator property tests assert their target diagnostic while retaining
  production rejection of unrelated findings.
- Reject incomplete, contradictory, crashed, or malformed validator results,
  including correct handling of multiline parser diagnostics.

## Verification

The release candidate must pass repository validation, the complete test suite,
shell syntax, ShellCheck, Ruff, and whitespace checks. Publication remains
subject to independent review and the exact release approval gate.
